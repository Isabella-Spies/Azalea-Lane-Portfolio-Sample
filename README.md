# Azalea Lane
A goal based decorating game

## About:
Azalea lane was a game that I started development of in late 2023. 
I set out to make a game for a phone that was a to-do app that rewarded you for getting things done
int the real world. You can add goals in your journal, complete them, then buy and place furniture in the room.

## Notes
The current build of this game is currently under development. As Azalea Lane is not yet ready for
a build for the phone, I have been refactoring the code so that the game is playable on a computer. 
There are still a few known U.I. bugs that are currently being fixed. The test build will be updated with those fixes soon.

## Instruction for End User
**Setting up the test build:**
1. Download the raw Build.zip folder
2. Extract Files
3. Run the "Azalea Lane" application file

**Adding a Goal**
1. From the home screen, click on the goals button on the bottom right corner.
2. Press the green plus button at the bottom center of the screen.
3. Use the input field to add a title
4. Select the type of goal you would like (Each yeilds a different amount of money upon completion)
5. Click on the green plus button to add the goal to the list.
   
**Completing a Goal**
1. Click on the box next to the goal that you would like to mark as complete

**Navigatng the Store Menu**
1. From the home page, click on the store button in the bottom left corner
2. Click on the furniture object that you would like to purchase (See build mode instructions)
Note: They can be sorted into categories using the tabs at the top

**Placing a Furniture Object From Build Mode**
1. Left click once to pick the object up
2. Move cursor around to move the object
3. Once the object is in the desired position, left click to drop the item
To rotate the object, use the left and right arrow buttons
To Confirm object placement, use the green check mark button
To cancel build mode press the red X button.

**Using Edit Mode**
1. From the store menu, select the "Edit Mode" tab
2. Right click an object to select it
3. Left click once to pick the object up
4. Move cursor around to move the object
5. Once the object is in the desired position, left click to drop the item
To rotate the object, use the left and right arrow buttons
To Confirm object placement, use the green check mark button
To cancel build mode, press the red X button.
To store to the inventory, Press the I button in the menu.

**Accessing the Inventory**
1. From the store menu, select the inventory tab
2. press the button of the object you would like to place
3. See build mode instructions.
